# Minigames in C (SDL2)

A collection of classic games implemented in C using the SDL2 framework. This repository includes Tic-Tac-Toe and Snake Game.

## Games

### 1. Snake Game
The classic arcade game where the player controls a snake to eat food and grow without hitting the walls or itself.
* Controls: Arrow Keys (Move), R (Restart), ESC (Quit)

### 2. Tic-Tac-Toe
A standard 3x3 grid game.
* Controls: Mouse Left Click (Place X/O), R (Restart)

## How to Build
Requires GCC and SDL2 development libraries.

1. Compile the code:
   make

2. Run the game:
   ./tictactoe

Note: Ensure SDL2.dll, SDL2_ttf.dll, and arial.ttf are located in the project directory.
