# Snake Game (C + SDL2)

A classic Snake game written in C using the SDL2 library.

## Controls
* Arrow Keys: Move
* R: Restart
* ESC: Quit

## How to Run
Requires GCC and SDL2 libraries.

1. Build the project:
   make

2. Run the game:
   ./tictactoe

Note: Ensure SDL2.dll, SDL2_ttf.dll, and arial.ttf are in the project folder before running.
